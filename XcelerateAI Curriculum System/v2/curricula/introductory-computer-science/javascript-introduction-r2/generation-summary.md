## Outcome

An eight-Week, 48-hour beginner path from first saved JavaScript program through a tested, persistent, documented, and published Node.js CLI. Setup is a separate 105-minute capability checklist and each capability is skippable only after verification.

- 3 phases, 22 atomic competencies, 28 contextual concept references, and 2 projects.

## Resource design

Resources were selected point by point from current Node.js, MDN, Microsoft Learn, JavaScript.info, Python Tutor, VS Code, and GitHub destinations. Videos establish a visual first model; bounded readable material supplies precision and fallback; Python Tutor provides active traces; official runtime and repository documentation is used only at exact operational boundaries. No external source is assigned as an unbounded whole course.
