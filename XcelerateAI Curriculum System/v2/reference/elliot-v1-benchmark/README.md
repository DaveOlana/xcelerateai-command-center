# Elliot V1 Curriculum Benchmark

This directory preserves a redacted, non-runtime copy of the historical Elliot JavaScript Mobile Ops curriculum supplied by the owner.

It is retained only as a comparison benchmark for instructional quality: dependency-aware progression, concrete practical missions, named files and features, debugging drills, test cases, proof requirements, session pacing, and a coherent product journey.

It is not authoritative V2 source, is not compiled, is not registered in the learner catalog, and must not be cloned or reskinned into other language curricula. Personal learner-name references are replaced with `Learner`; the educational structure and product-specific Elliot content are otherwise preserved.
