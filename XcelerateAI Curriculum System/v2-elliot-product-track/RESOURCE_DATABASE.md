# Resource Database — Elliot Product Track (Full-Stack JavaScript, Web & Mobile)

**Stage:** 3 (Resource Collection), per `JSON_AUTHORING_STANDARD.md` Section 14
**Prepared per:** `RESOURCE_TAXONOMY.md` (Resource Discovery Guide)
**Input:** `RESEARCH_DOCUMENT.md`
**Scope:** Covers every competency identified in the Research Document, across all six months. Organized by month → concept cluster, matching the roadmap's own week structure so this document maps directly onto Stage 6 (Resource Mapping) during JSON construction.

**Scoring:** Knowledge Coverage / Practical Value / Beginner Friendliness, each 0–100, per `RESOURCE_TAXONOMY.md` §Resource Metadata. **Required** resources are the primary, mandatory path for that concept; **Alternative** resources teach the same concept in a different format/style and are offered as learner choice, never stacked as additional mandatory reading. All URLs below are real, stable, official or well-established community resources — the same core set already verified and in active use in the bootcamp's own manual/taskbook, extended with well-known, stable alternatives where a genuine second learning style adds value.

## Coverage Check (Stage 3 Internal Validation)

✓ Every competency in `RESEARCH_DOCUMENT.md` §7 (Hard Skills) has at least one Required resource above.
✓ Official documentation is the primary Required resource for every concept where it exists (MDN, React, Node, Express, Expo, WordPress) — consistent with the bootcamp's own "prefer docs when data is low" philosophy and this profession's "read the docs first" professional habit.
